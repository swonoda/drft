# DRFT ユーザーマニュアル

[READMEへ戻る](../README.md)

## 1. 原稿を作成する

「ファイル」メニューから「新規作成」または「開く…」を選択します。新規作成した原稿は空の状態で開きます。

DRFTが編集する原稿形式はTXTです。独自形式への変換やプロジェクトファイルの作成は行いません。

### 保存と自動保存

- `Ctrl/Cmd+S`：保存
- `Ctrl/Cmd+Shift+S`：名前をつけて保存
- 保存前の変更がある場合、画面左下に「未保存」と表示
- 一度保存先を決めた原稿は、入力が止まってから約1.2秒後に自動保存
- 前回終了時に開いていた保存済み原稿は、次回起動時に復元

新規原稿は保存先が決まるまで自動保存されません。

### 文字コード

画面右下に現在の文字コードが表示されます。クリックして次の形式を切り替えられます。

- UTF-8
- Shift_JIS

既存のTXTを開いたときは文字コードを自動判定します。表示を切り替えると、その形式で次回の保存が行われます。

### 文字数と原稿用紙換算

画面右下に本文の文字数と400字詰め原稿用紙の枚数を表示します。原稿用紙枚数は文字数を400で割り、余りを切り上げて計算します。

改行、ルビ・傍点の記法、`#fix`は文字数に含みません。全角空白と句読点はそれぞれ1字として数えます。

## 2. 原稿の構造

DRFTは空行からタイトル・章・節を判別します。

| 原稿上の位置・空行 | DRFTでの扱い |
| ------------------ | ------------ |
| 先頭の1行          | タイトル     |
| 1行空き            | 節の区切り   |
| 2行空きの次の行    | 章見出し     |
| 節先頭の全角空白   | 一字下げ     |

```text
作品タイトル


第一章

　ここから本文を書きます。
```

章と節は左側の構成ビューへ表示されます。

- 項目をクリック：本文の該当位置へ移動
- 節をドラッグ＆ドロップ：節単位で並べ替え
- 「表示」→「構成を表示／非表示」：構成ビューを開閉

章見出しは節の親として表示されます。章自体はドラッグ＆ドロップの対象外です。

## 3. 編集と検索・置換

本文は横書きのエディタで編集します。

「編集」メニューまたはショートカットから検索・置換画面を開けます。

- 次を検索：カーソルより後ろにある一致箇所へ移動。末尾まで到達すると先頭へ戻る
- 置換：選択中の一致箇所を置換して次へ移動
- すべて置換：原稿内の一致箇所を一括置換

## 4. 縦書きプレビュー

画面右上の本のアイコン、または「表示」→「縦書きプレビューを表示／非表示」からプレビューを開閉します。

プレビューはページ単位で表示されます。

- 左側の `‹`：次のページ
- 右側の `›`：前のページ
- エディタのカーソルを移動：該当する文とページへ追従
- カーソルを含む文：若草色の背景で表示

エディタの本文はプレビューを開いた幅に合わせて狭くなり、左右余白も自動調整されます。

### 修正箇所の表示

プレビュー右上の「修正表示」で、`#fix`が付いた文の淡い赤色の背景を表示・非表示にできます。`#fix`そのものはプレビューへ表示されません。

### 表示設定

「表示」→「表示設定…」から次の項目を変更できます。

- フォント
- 文字サイズ
- 文字間
- 行間
- 一行の文字数
- 1ページの行数
- 上下余白
- 左右余白

設定はエディタと縦書きプレビューへ反映され、次回起動時にも引き継がれます。

縦書き用でないフォントでは、長音記号「ー」などが正しい向きで表示されない場合があります。その場合は縦書きに対応したフォントを指定してください。

### ゲラPDFから文字数と行数を読み取る

「ツール」→「組版を調整…」からサンプルとなるゲラPDFを選択すると、本文領域を解析して一行の文字数と1ページの行数を推定します。確認画面で反映すると、表示設定へ値が入力されます。

## 5. 修正マーク

本文中に次の形式で記述します。

```text
白熊は水平線を見つめていた。#fix[季節が分かる描写を追加]
```

コメントを省略することもできます。

```text
#fix[]
```

左側の「修正」タブには、コメントと該当箇所の文が一覧表示されます。

- 一覧をクリック：本文の該当位置へ移動
- 本文から`#fix[...]`を削除：一覧からも削除
- 修正タブの数字：現在残っている修正マークの件数

修正マークはTXTにはそのまま保存されますが、文字数、通常の縦書き本文、PDF、EPUBには含まれません。

## 6. 辞書

「表示」→「辞書」から、開いている作品専用の辞書を別ウィンドウで開きます。

辞書の項目は次の2つだけです。

- 見出し
- 説明

「＋ 追加」で項目を作成し、内容を変更すると保存ボタンが有効になります。`Ctrl/Cmd+S`でも保存できます。

辞書の一覧で見出しをクリックすると、本文にある同じ文字列へ移動します。繰り返しクリックすると次の出現箇所へ進みます。辞書上部の検索欄では、見出しと説明を絞り込めます。

辞書は原稿と同じフォルダへMarkdownとして保存されます。

```text
作品名/
├── 作品名.txt
└── 作品名_辞書.md
```

辞書ファイルの内容は次の形式です。ほかのMarkdownエディタで編集することもできます。

```markdown
# 登場人物名

人物についての説明。

# 地名

場所についての説明。
```

以前のバージョンで作成した `辞書.md` が同じフォルダにある場合は読み込みます。次に保存すると、原稿ごとのファイル名へ移行します。

## 7. スナップショット

大きく書き換える前の原稿を別ファイルとして残す機能です。

「ファイル」→「スナップショットを保存…」を選択すると保存先の確認画面が開きます。保存済み原稿の場合、原稿と同じ場所に `スナップショット` フォルダを作り、日時を含む名前を初期値として使用します。

```text
作品名/
├── 作品名.txt
├── 作品名_辞書.md
└── スナップショット/
    └── 作品名_スナップショット_20260814-123456.txt
```

スナップショットを保存しても、現在編集中のファイルは切り替わりません。スナップショットの一覧表示や差分履歴の自動作成は行いません。

## 8. ファイル比較

「ツール」→「ファイルを比較…」を選択すると比較ウィンドウが開きます。

- 左：古いファイル
- 右：新しいファイル。比較を開いた時点では、メイン画面で編集中の原稿を使用

左右のファイル名をクリックすると、それぞれ別のTXTへ変更できます。別々のフォルダにあるファイルも選択可能です。

### 差分表示

「差分」では2つの原稿を並べ、変更された文字列を単語単位で表示します。

- 左右のスクロール位置は同期
- 上部の `‹` `›` で前後の変更箇所へ移動
- 左右のファイルは表示専用。比較画面から原稿を書き換える機能はありません

### 校正原稿

「校正原稿」へ切り替えると、古い原稿の縦書き組版へ変更内容を赤字で重ねます。

- 削除：該当文字へ取り消し線を引き、「トル」を表示
- 置換：元の文字へ取り消し線を引き、変更後の文字列を行間または余白へ表示
- 追加：挿入位置へ `＜` を置き、引出線で追加文字列へ接続

赤字は本文と別のレイヤーへ描画されるため、元の組版を変更しません。

校正原稿の左側にある開閉ボタンからレイアウト調整ペインを表示できます。

- フォント
- 上下余白
- 左右余白
- 1ページの行数
- 1行の文字数
- サンプルPDFから設定

ページ領域の左右にある `‹` `›` で見開きを切り替えます。画面右下のダウンロードボタンから、表示中の校正原稿を朱入り原稿PDFとして保存できます。

校正記号の配置は自動処理です。変更箇所が密集している場合、引出線や注記が重なることがあります。

## 9. PDF・EPUB出力

「ファイル」→「エクスポート」から出力形式を選択します。

### PDF

表示設定のフォント、文字サイズ、字間、行間、一行の文字数を反映したA5縦書きPDFを作成し、右綴じの見開きへ面付けします。

本文先頭は論理2ページ目、つまり最初の見開きの左側へ配置され、右側は空白になります。

```text
見開き1  [ 2ページ ] [ 空白 ]
見開き2  [ 4ページ ] [ 3ページ ]
見開き3  [ 6ページ ] [ 5ページ ]
```

トンボと裁ち落とし指定にはChromiumの印刷機能を利用しています。商業印刷用データとしての完全な互換性は保証していません。

### EPUB

縦書きのリフロー型EPUB 3を出力します。

- 先頭行からタイトルページを作成
- 章見出しだけを目次へ登録
- 章ごとに改ページ
- ルビと傍点を反映
- `#fix`を除外

ページ数、フォント、余白などの表示結果はEPUBリーダーによって異なります。

## 10. 対応記法

### ルビ

青空文庫記法とカクヨム記法に対応しています。

```text
｜流氷《りゅうひょう》
|流氷《りゅうひょう》
流氷《りゅうひょう》
```

### 傍点

```text
重要［＃「重要」に傍点］
《《重要》》
```

傍点は縦書き向けのゴマで表示されます。

## 12. ファイル構成

DRFTが作品のために作成するファイルとフォルダは次のとおりです。

```text
作品名/
├── 作品名.txt
├── 作品名_辞書.md
└── スナップショット/
    └── 作品名_スナップショット_日時.txt
```

PDF、EPUB、朱入り原稿PDFは、出力時に指定した場所へ保存します。DRFTは上記以外のファイルやサブフォルダを変更しません。
