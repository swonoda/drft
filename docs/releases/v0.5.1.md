# DRFT v0.5.1

長文原稿の末尾で日本語入力・変換・確定が遅れる問題を改善しました。20万字を超える原稿でも全文を一続きで編集できます。

## 主な変更

### 長文の日本語入力を改善

- 本文エディタをCodeMirror 6へ移行し、画面に必要な範囲だけを描画する方式に変更
- 20万字超の原稿で、末尾の入力遅延が解消したことをユーザーのWindows環境で確認
- IME変換中は目次・文字数などの更新と自動保存を保留し、確定後に再開
- 目次や検索結果へ移動する際のスクロール処理を変更
- Undo／Redo、全選択、検索置換、保存、プレビュー、表示設定を新しい入力欄へ接続
- 保存処理中の追記を誤って「保存済み」と表示する問題を修正
- ファイル切替時に編集履歴と保留中の更新処理をリセット

### 赤ゲラPDFの反映画面を追加

- 「ツール → ゲラを原稿に反映…」から原稿と赤ゲラPDFを並べて確認
- 赤い書き込みの位置を検出し、変更箇所の一覧から該当位置へ移動
- 修正内容を手入力し、確認後に本原稿へ反映
- 反映前の原稿をスナップショットとして保存
- PDFのページ表示、縦書きの位置対応、ハイライトと移動処理を改善

赤字の内容を自動で文字認識する機能ではありません。変更箇所の検出にはPythonとOpenCVの準備が必要です。配布ZIPに含まれる `setup-proof.cjs` を、Python 3.12とNode.js 22.12以降を用意した環境で `node setup-proof.cjs` として実行してください。ソースコードから利用する場合は `npm run proof:setup` でも準備できます。

### その他

- 「ツール → 開発者ツール」を追加（Windows/Linux: Ctrl+Shift+I、macOS: Option+Command+I）
- 調査用の入力診断表示・計測処理は削除

## ソースコードから更新する場合

依存関係が追加されています。更新後に `npm install` を実行してから `npm start` で起動してください。入力欄のバンドルは起動時に自動生成します。
