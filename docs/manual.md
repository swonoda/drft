# DRFT ユーザーマニュアル

[READMEへ戻る](../README.md)

## 1. 原稿を作成する

「ファイル」メニューから「新規作成」または「開く…」を選択します。新規作成した原稿は空の状態で開きます。

DRFTで編集する原稿形式はテキストファイルとして保存されます。

### 保存と自動保存

- `Ctrl/Cmd+S`：保存
- `Ctrl/Cmd+Shift+S`：名前をつけて保存

保存前の変更がある場合、画面左下に「未保存」と表示されます。入力が止まると自動保存が行われます。ただし新規原稿は保存先が決まるまで自動保存されません。


起動時は、前回終了時に開いていた保存済み原稿が表示されます。

### 文字コード

画面右下に現在の文字コードが表示されます。ファイルを開くと自動で文字コードが判定されます。

対応文字コードは下記の二種類です。

- UTF-8
- Shift_JIS

クリックで文字コードを切り替え、保存するとファイルの文字コードを変更することができます。


### 文字数と原稿用紙換算

画面右下に本文の文字数と400字詰め原稿用紙の概算枚数を表示します。

文字数に改行、ルビ・傍点の記法、`#fix`タグは含まれません。全角空白と句読点はそれぞれ1字として数えます。

## 2. 原稿の構造

DRFTは空行からタイトル・章・節を判別します。

| 原稿上の位置・空行 | DRFTでの扱い |
| ------------------ | ------------ |
| 先頭の1行          | タイトル     |
| 1行空き            | 節の区切り   |
| 2行空きの次の行    | 章見出し     |


章と節は左側の構成ビューに表示されます。

- 項目をクリック：本文の該当位置へ移動
- 節をドラッグ＆ドロップ：節単位で並べ替え

表示メニューから構成を表示/非表示をクリックすると、左の構成ペインを開閉できます。

章見出しは節の親として表示されます。章はドラッグ＆ドロップの対象外です。

## 3. 縦書きプレビュー

画面右上の本のアイコン、または「表示」→「縦書きプレビューを表示／非表示」からプレビューを開閉します。

プレビューは「表示」→「表示設定…」の設定で描画されます。ページ送りはプレビュー上部の`<`、`>`をクリックしてください。ページを送るとエディタもプレビューに表示されている領域へ移動します。

エディタのカーソルを含む文は若草色の背景で表示されます。



### 修正箇所の表示

プレビュー右上の「修正表示」で、`#fix`が付いた文の淡い赤色の背景を表示・非表示にできます。`#fix`そのものはプレビューへ表示されません。

### 表示設定

「表示」→「表示設定…」から次の項目を変更できます。

- フォント
- 文字サイズ
- 文字間
- 行間
- 一行の文字数
- 1ページの行数
- 上下余白
- 左右余白

設定はエディタと縦書きプレビューへ反映され、次回起動時にも引き継がれます。

※縦書き対応フォント以外を使用すると、長音記号などが正しく表示されない場合があります。

### ゲラPDFから文字数と行数を読み取る

「ツール」→「組版を調整…」からサンプルとなるゲラPDFを選択すると、本文領域を解析して一行の文字数と1ページの行数を推定します。確認画面で反映すると、表示設定へ値が入力されます。

※余白に手書き文字等があると正しく反映されない場合があります

## 4. 修正マーク

本文中に次の形式で記述します。

```text
小田原熱海あたみ#fix[ルビ記法に変更する]に、軽便鉄道敷設ふせつの工事が始まったのは、良平の八つの年だった。
```

コメントは省略できます。

```text
#fix[]
```

左側の「修正」タブに、コメントと該当箇所の文が一覧表示されます。

- 一覧をクリック：本文の該当位置へ移動
- 本文から`#fix[...]`を削除：一覧からも削除
- 修正タブの数字：現在残っている修正マークの件数

修正マークはテキストファイルにはそのまま保存されますが、文字数、通常の縦書き本文、PDF/EPUB出力には含まれません。

## 5. 辞書

「表示」→「辞書」から、作品専用の辞書を別ウィンドウで開きます。
辞書には見出しとなる単語とメモを登録することができます。

作品独自の単語や登場人物名などの固有名詞を登録し、説明にメモや設定などを入力することを想定しています。


「＋ 追加」で項目を作成し、内容を変更すると保存ボタンが有効になります。`Ctrl/Cmd+S`でも保存できます。

辞書の一覧で見出しをクリックすると、本文にある同じ文字列へ移動します。繰り返しクリックすると次の出現箇所へ進みます。辞書上部の検索欄では、見出しと説明を絞り込めます。

辞書は原稿と同じフォルダに.mdファイルとして保存されます。

```text
作品名/
├── 作品名.txt
└── 作品名_辞書.md
```

■ファイルの内容（例）
```markdown
# クー・ザルカ・ザンガス

クー・ザルカ・ザンガスという人物は～

# ドゥジの背骨

ドゥジの背骨はかつて巨人が～
```
.mdファイルはテキストファイルのため、メモ帳などで編集することも可能です（DRFTでは読み込むことができません）。


原稿と同じフォルダに `{ファイル名}_辞書.md` が存在する場合は自動で読み込みます。

## 6. スナップショット

構成等を大きく変える前にスナップショットを作成することができます。

「ファイル」→「スナップショットを保存…」を選択すると保存先の確認画面が開きます。保存済み原稿の場合、原稿と同じ場所に `スナップショット` フォルダを作り、日時を含む名前を初期値として使用します。

```text
作品名/
├── 作品名.txt
├── 作品名_辞書.md
└── スナップショット/
    └── 作品名_スナップショット_20260814-123456.txt
```


## 7. ファイル比較

「ツール」→「ファイルを比較…」を選択すると比較ウィンドウが開きます。

- 左：古いファイル
- 右：新しいファイル（現在編集中のファイル）


左右のファイル名をそれぞれクリックすると、別のファイルへ変更することができます。別々のフォルダにあるファイルも選択可能です。

### 差分表示

「差分」では2つの原稿を並べ、変更された文字列を単語単位で表示します。

- 左右のスクロール位置は同期
- 上部の `‹` `›` で前後の変更箇所へ移動

※比較画面から原稿を書き換えることはできません。また比較画面表示中にエディタで原稿を変更しても、比較画面には反映されません。

### 校正原稿（β版）

比較画面の上部にある「校正原稿」をクリックすると、古い原稿の縦書き組版に校正記号を使用して変更内容を反映させます。

- 削除：該当文字へ取り消し線を引き、「トル」を表示
- 置換：元の文字へ取り消し線を引き、変更後の文字列を行間または余白へ表示
- 追加：挿入位置へ `＜` を置き、引出線で追加文字列へ接続

赤字は本文と別のレイヤーへ描画されるため、元の組版を変更しません。

校正原稿の左側にある開閉ボタンからレイアウト調整ペインを表示できます。

- フォント
- 上下余白
- 左右余白
- 1ページの行数
- 1行の文字数
- サンプルPDFから設定

ページ領域の左右にある `‹` `›` で見開きを切り替えます。画面右下のダウンロードボタンから、表示中の校正原稿をPDFとして出力することができます。

校正記号の配置は自動処理です。変更箇所が密集している場合、引出線や注記が重なることがあります。



## 8. PDF・EPUB出力

「ファイル」→「エクスポート」から出力形式を選択します。

### PDF

表示設定のフォント、文字サイズ、字間、行間、一行の文字数を反映したA5縦書きPDFを作成し、右綴じの見開きへ面付けします。

本文先頭は論理2ページ目、つまり最初の見開きの左側へ配置され、右側は空白になります。

```text
見開き1  [ 2ページ ] [ 空白 ]
見開き2  [ 4ページ ] [ 3ページ ]
見開き3  [ 6ページ ] [ 5ページ ]
```

トンボと裁ち落とし指定にはChromiumの印刷機能を利用しています。商業印刷用データとしての完全な互換性は保証していません。

### EPUB

縦書きのリフロー型EPUB 3を出力します。

- 先頭行からタイトルページを作成
- 章見出しだけを目次へ登録
- 章ごとに改ページ
- ルビと傍点を反映
- `#fix`を除外

ページ数、フォント、余白などの表示結果はEPUBリーダーによって異なります。

## 9. 対応記法

### ルビ

青空文庫記法とカクヨム記法に対応しています。

```text
｜流氷《りゅうひょう》
|流氷《りゅうひょう》
流氷《りゅうひょう》
```

### 傍点

```text
重要［＃「重要」に傍点］
《《重要》》
```

傍点は縦書き向けのゴマで表示されます。

## 11. ファイル構成

DRFTが作品のために作成するファイルとフォルダは次のとおりです。

```text
作品名/
├── 作品名.txt
├── 作品名_辞書.md
└── スナップショット/
    └── 作品名_スナップショット_日時.txt
```

PDF、EPUB、朱入り原稿PDFは、出力時に指定した場所へ保存します。DRFTは上記以外のファイルやサブフォルダを変更しません。
