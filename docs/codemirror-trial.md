# CodeMirror 6 長文入力の試験版

20万字程度の原稿で末尾の日本語入力が遅れる症状を比較するため、本文入力欄を CodeMirror 6 に置き換えています。原稿全体は一つの文書として保持し、画面に必要な範囲だけをDOMに描画します。章ごとに原稿を分割する操作はありません。

## 起動

```sh
git fetch origin
git switch experiment/codemirror-long-document
npm install
npm start
```

`npm start` と `npm run dist:win` は、起動・配布前に入力欄のコードを自動でバンドルします。生成先は `src/generated/` です。実行時にCDNへの接続は不要です。Electronを直接実行する場合は、先に `npm run build:editor` を実行してください。

## 比較する操作

同じ長文ファイル・表示設定で、プレビューを閉じて次を比較してください。

1. 冒頭と末尾それぞれで日本語を入力し、途中で1秒以上止めてからスペースで変換、Enterで確定する。
2. 入力文字・変換候補が表示されるまでの待ち時間、確定直後の追加入力を確認する。
3. 末尾への目次／検索ジャンプ、複数段落の選択・コピー・貼り付け、Undo／Redoを試す。
4. 保存して開き直し、全文と末尾の編集が残っていることを確認する。

開発者ツールは引き続き利用できます。変換中は目次・文字数などの遅延更新と自動保存を保留し、確定後に再開します。手動保存は従来どおり可能です。

この変更で実際のWindows IMEの遅延が解消するかは、実機での比較が必要です。

## 自動検証

```sh
npm test
npx playwright install chromium
npm run test:editor
```

`npm test` は20万字の文書データ・Undo/Redo・全選択・改行の整合性を含みます。DOMエミュレーターでの検証なので、描画速度やIMEの検証にはなりません。

`test:editor` は実際のChromiumで204,084字を読み込み、末尾入力・合成入力イベント・保存・検索置換・ファイル切替・表示設定を確認するためのテストです。ファイルIPCを模擬しており、OSのIME候補ウィンドウやElectronのメニューは実機で確認してください。実装環境ではChromium起動が権限制限で拒否されたため、このブラウザーテストは未完走です。
